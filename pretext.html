Traditional DOM-based highlighting

The original MarkerHighlighter works on existing HTML with <mark> tags — no pretext needed. Both approaches coexist in the same library.

The standard MarkerHighlighter scans for <mark> elements in the DOM and overlays canvas-drawn highlights at the positions returned by getClientRects(). This is the simplest way to add animated highlighting to any webpage — just wrap text in <mark> tags and initialize the library.

It works beautifully for most use cases where text is already in the page. The pretext-powered approach above is for scenarios where you need maximum layout performance — multi-column layouts, text flowing around obstacles, or real-time resize without jank.
